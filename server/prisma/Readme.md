
# Parkly

A parking space rental marketplace that connects drivers looking for parking with parking space owners.

## Tech Stack

### Frontend
- React.js
- Vite
- CSS
- React Leaflet
- OpenStreetMap

### Backend
- Node.js
- Express.js
- PostgreSQL
- Prisma ORM
- JWT Authentication
- Razorpay
- Nodemailer

## Features

- User registration and authentication
- Driver and parking provider roles
- Search parking spaces by area
- Interactive maps with parking locations
- Parking listing creation and editing
- Booking management
- Razorpay payment integration
- Booking email notifications
- Automatic booking status updates
- Driver and provider dashboards

## Local Development

### Frontend
```bash
cd client
npm install
npm run dev
```

### Backend
```bash
cd server
npm install
npm start
```

Configure your environment variables using the provided `.env.example` files.
